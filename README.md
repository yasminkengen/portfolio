# 💼 Portfólio Profissional Premium — Yasmin Kengen

Este é o repositório do portfólio digital premium, sofisticado, moderno e minimalista desenvolvido para **Yasmin Kengen**, profissional com foco em **Assistência Administrativa, Financeira, Atendimento ao Cliente e Suporte Executivo**.

O objetivo deste projeto é ir além de um currículo tradicional, servindo como uma plataforma ativa de conversão e atração para recrutadores, pequenas empresas, profissionais liberais, startups e clientes de freelancing.

---

## 🎨 Identidade Visual & Design

O visual foi projetado para transmitir **elegância, organização, confiança, discrição e credibilidade**, inspirado no estilo de grandes empresas e ferramentas modernas (como Deloitte, Stripe, Linear e Notion).

*   **Paleta de Cores Estrita:**
    *   `Preto (#1F1F1F)` — Base sólida para tipografia e contraste premium.
    *   `Branco (#FFFFFF)` — Fundo limpo, priorizando o respiro visual e o espaço em branco.
    *   `Cinza Claro (#F5F5F5)` — Tons suaves para divisões sutis e grids.
    *   `Dourado Fosco (#C8A96A)` — Cor de destaque para detalhes de alto padrão, botões de ação e ícones.
*   **Tipografia Refinada:** Utilização de fontes modernas com boa legibilidade corporativa e hierarquia visual bem estabelecida.
*   **Micro-animações:** Efeitos suaves de *fade-in*, *scale* nos elementos e transições discretas de hover para manter a interface viva e interativa.

---

## 🚀 Funcionalidades Principais

*   **🌐 Sistema de i18n Dinâmico (Multilíngue):** Suporte nativo para **Português (PT)**, **Inglês (EN)** e **Espanhol (ES)**. As traduções são alternadas instantaneamente via JavaScript sem necessidade de recarregar a página.
*   **🤝 Integração de Parceria Tecnológica:** Seção dedicada ao parceiro tecnológico (Carlos André, Desenvolvedor Full Stack) para apresentar a capacidade de entrega de soluções completas de tecnologia, automações e sistemas.
*   **📱 Responsividade Fluida:** Grid de serviços e seções totalmente adaptáveis para telas Desktop (4 colunas), Tablets (2 colunas) e Mobile (1 coluna).
*   **📞 Chamadas de Ação Inteligentes:** Integração direta para contatos por E-mail, WhatsApp e acesso ao perfil do LinkedIn da profissional.
*   **⚡ Performance e SEO:** Desenvolvido puramente com tecnologias nativas (HTML, CSS e JS puros), garantindo carregamento ultrarrápido, sem dependências pesadas e otimizado para motores de busca.

## 💻 Como Rodar o Projeto Localmente

1. Clone este repositório para o seu ambiente local:
   ```bash
   git clone https://github.com/yasminkengen/portfolio.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd portfolio
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência ou execute utilizando extensões de servidor local (como *Live Server* do VS Code).
